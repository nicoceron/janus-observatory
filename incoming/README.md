# Restricted intake

Place author-supplied, unlicensed, embargoed, or permission-bearing material here. Everything below
this directory is ignored by Git except placeholder files.

Expected destinations:

- `janus-authors/collapse-recovery/` — source code, seeds, configurations, and raw simulations.
- `janus-authors/spectra/` — PSG/LIFEsim inputs, curves, noise products, and run metadata.
- `permissions/zenodo-pipelines/` — written reuse permission or a snapshot of updated license metadata.
- `permissions/water-zither/` — permission from CJ Baal or the rights holder.

Do not move any item into the public application or `data/sources/files/` until its license and
attribution requirements have been recorded in the source manifest.
