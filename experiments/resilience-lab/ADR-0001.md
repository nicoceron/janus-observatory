# ADR-0001: Independent reimplementation semantics for the collapse-recovery model

Status: accepted
Date: 2026-08-21
Scope: `experiments/resilience-lab`

## Context

The collapse-recovery paper (JANUS-PAPER-05, arXiv:2604.13774v1, CC BY 4.0) defines the
model through Equations (1)-(3), a hazard rule, and prose about recovery timing, but
does not pin down every yearly-step detail. A public author repository (`technocycles`,
commit `910770d`) exists but declares no license, so it is cited and not copied; the
master plan requires this experiment's implementation to remain independent.

## Decisions

Each choice below is implemented identically in all three representations (reference
simulator, event-driven sampler, analytic recursions) and covered by validation.

1. **Active step definition.** A step is active iff the system is not inside recovery
   delay and holds R > 0. Growth and depletion apply during active steps only.
2. **The collapse year counts as active.** The system operated during that step before
   collapsing at its end.
3. **Hazard-before-resource tie-breaking.** If both triggers land on the same step the
   cause is recorded as `hazard`, because the paper's hazard deviate is evaluated per
   step "independently of resource levels". The event sampler uses the same rule via
   k_hazard <= k_resource.
4. **Recovery delay semantics.** After a collapse, rd subsequent steps are inactive;
   resources are restored to rf x R0 at the end of the last inactive step, so activity
   resumes on the next step. With rd = 0 restoration happens immediately at the
   collapse transition.
5. **Hazard draws during active steps only.** Drawing hazards during dormancy would
   extend recovery beyond rd, contradicting "remains inactive for rd time steps".
6. **Extinction.** If rf x R0 <= 0 after a collapse the run stays OFF permanently.
7. **First-collapse year** is the 1-based step index in which the collapse occurred;
   censored runs contribute the full window to the paper-style truncated mean, and are
   right-censored in all survival analyses instead.
8. **Table 5 interpretation.** "+/-5% of mean" is read as a normal standard deviation of
   5% of the mean (delta clipped at zero); triangular distributions span mode +/-5%
   clamped to [0,1]; rd is normal with 10-year standard deviation truncated at zero and
   rounded to integer years; r and h are held fixed per scenario batch.
9. **Scenario seeds.** A batch uses one NumPy generator stream for parameter
   perturbations followed by event/hazard draws. Large ensembles use
   `12345 + scenario_number * 101`; the direct comparability batch uses the
   paper-documented generator seed `12345` with 200 replicates. Both the base seed and
   per-scenario derived seeds are serialized in the report.

## Consequences

- Replication against every prose-reported aggregate passes within documented
  tolerances (`reports/replication-report.json`); S3/S10 match exactly.
- The one visible divergence is S5's never-collapsed fraction: the model pins it at
  (1 - h)^1000 = 0.6066 while the paper reports ~0.66 from 200 runs; binomial noise at
  that ensemble size covers most of the gap, so no semantic change was introduced.
- Any future change to these semantics must update ADR-0001, all three
  representations, and the tolerance table together, or equivalence tests will fail.
